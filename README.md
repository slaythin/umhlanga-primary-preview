# Umhlanga Primary — Client Preview

Client review of the Umhlanga Primary School website concept.

The site is a self-contained static `index.html` with embedded fonts, photography and scripts. It includes the golden-book introduction, school galleries, educator profiles, organogram, and founding-family message.

## Hosting

GitHub Pages publishes from the root of the `main` branch. Replace `index.html` and commit to `main` to update the preview.

This is a public design preview. A `noindex,nofollow` meta tag asks search engines not to index it; it is not access protection.

## Local preview

Open `index.html` in a modern browser. No installation or build step is needed.
